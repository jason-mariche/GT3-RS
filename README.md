# GT3-RS

Git project for OpenCode on the Asus Vivobook 18 (GT3-RS).

## Purpose

This repository tracks configuration, notes, and working files for the OpenCode setup running on the Asus Vivobook 18 laptop (codename GT3-RS).

## Structure

```
GT3-RS/
├── .gitignore
└── README.md
```

## Getting Started

1. Clone the repo:
   ```bash
   git clone https://github.com/jason-mariche/GT3-RS.git
   ```
2. Open the directory in OpenCode.

## Notes

- Host machine: Asus Vivobook 18
- Project codename: GT3-RS
- OpenCode working directory: `C:\Users\Business\Projects\GT3-RS`
